Topsl's v0.1.3 personal pilot packages everything committed to `main` since v0.1.2 (up to `9b491f1`, 21 October 2026) so the owner can test it as an installed app. It adds coordinator teams, experimental Recursive Looping, Claude Code workflows and provider permission controls, and carries the repairs from the comprehensive test campaign.

- **Coordinator teams.** A persistent project conversation backed by role groups with any number of members per role, coordinator rounds with endorsements, review groups with bounded repair, required checks and a natively confirmed **Apply to project folder**. Coordinators who propose the same work in different words no longer need an owner choice. See [Coordinator teams](../Coordinator_Teams.md).
- **Recursive Looping (experimental, off by default).** Goal and Endless runs above the coordinator engine, behind `experimental.recursiveLooping`. Bounded live Codex-only and mixed Claude/Codex loops have completed on the owner's Mac; this is not broad live qualification. See [Recursive Looping](../Recursive_Looping.md).
- **Claude Code workflows.** Claude Code can build, review or both, through steps run in its own terminal with an optional transcript read, and, as an owner decision, through Claude Code's structured route under a Claude qualification.
- **Codex workflows and permissions.** Codex reviews Codex with Topsl's candidate reader, a clearer approval card, permission modes for native terminals, four Codex chat presets and an opt-in **Settings → Auto-accept**.
- **Usage and interface.** Usage remaining with Claude Code's native `/usage` reading, and the Navigator's Atlas interface with the project command desk, Sessions and Coordinator views.
- **Defect repairs.** Every defect the comprehensive test campaign and the 20 October live runs recorded (D-01 to D-29) is repaired or decided, and streamed message text is written in batches instead of once per delta. See [defects and decisions](../testing/TEST-DECISIONS.md).

Downloads include macOS Apple silicon and Intel ZIPs, a Windows x64 portable EXE, and a Linux x64 AppImage. Each package has a matching `.sha256` checksum file. Extract the macOS ZIP before opening the app; on Linux, make the AppImage executable before launching it.

These packages are unsigned personal-pilot builds without Developer ID notarization or Windows publisher signing. Mac bundles carry an ad-hoc signature, so macOS may ask for approval under **System Settings → Privacy & Security → Open Anyway**. This prerelease does not certify vendor installation/update flows, live paid model execution across providers, or complete native sidebar mirroring. Most coordinator and loop coverage comes from stand-in runtimes; see [Implementation status](../Implementation_Status.md) for what live runs established.

Publication requires all four platform builds, automated tests, desktop acceptance smoke tests, extracted Mac bundle verification, and uploaded-package checksum checks to pass.
