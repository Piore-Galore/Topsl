Topsl's personal-pilot release brings a shared local project catalog to the native Codex and Claude workbench.

This release repairs the Linux upload failure in the unpublished v0.1.0 draft. The release workflow now recognizes electron-builder's `x86_64.AppImage` filename and checks package naming against the installed packager for every platform.

- Discover native project folders and keep their local identities and history together.
- Register trusted folders in Codex, mirror its project names and order in Topsl, and rename or reorder native groups.
- Open shared folders in Claude Code through native folder links.
- Retain encrypted local history, native terminals, reviewed configuration changes, and application management.

Downloads include macOS Apple silicon and Intel ZIPs, a Windows x64 portable EXE, and a Linux x64 AppImage. Each package has a matching `.sha256` checksum file. Extract the macOS ZIP before opening the app; on Linux, make the AppImage executable before launching it.

These packages are unsigned personal-pilot builds. OS publisher checks still apply. This prerelease does not certify vendor installation/update flows, paid model execution, or complete native sidebar mirroring. Codex's project API is experimental and its visible desktop sidebar can keep a separate cache; Claude requires native folder confirmation and its project-list editing API has not been verified.

Publication requires all four platform builds, automated tests, desktop acceptance smoke tests, and uploaded-package checksum checks to pass.
